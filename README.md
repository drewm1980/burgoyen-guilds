# Cohousing Bourgoyen: planting proposals

Slides for three planting proposals (heartnut next to the bike shed, chestnut in the north, a diverse plum patch) plus two cherry trees.

- **English slides:** https://drewm1980.github.io/burgoyen-guilds/
- **Nederlandse dia's:** https://drewm1980.github.io/burgoyen-guilds/index.nl.html
- Research notes behind the slides (English): [docs/garden_guilds_research.md](docs/garden_guilds_research.md)

## Maintaining

The slides are Markdown ([Marp](https://marp.app/)): `docs/garden_guilds.marp.md` (English) and `docs/garden_guilds.nl.marp.md` (Dutch). Keep both in step, then run `./build.sh` to regenerate `docs/index.html` and `docs/index.nl.html`. GitHub Pages serves the `/docs` folder of `main`.
