## Project Overview

This is a garden design document repository for **Cohousing Bourgoyen**, a cohousing community in Ghent, Belgium. The project is managed in Dutch. Work here involves reviewing, summarizing, and helping develop design documents — not software development.

## Site Layout

From the inplantingsplan (site plan), the property contains:
- **1** Inrijdreef (driveway entrance)
- **2** Gemeenschappelijke woning (common house) — central building
- **3** 8 privatieve woningen (8 private homes)
- **4** Brievenbussen (mailboxes)
- **5** Parkeerplaatsen bewoners (resident parking)
- **6** Fietsenstalling (bicycle storage)
- **7** Serre (greenhouse/conservatory)
